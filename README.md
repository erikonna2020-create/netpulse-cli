# NetPulse CLI

Компактная консольная утилита на Python для базовой сетевой диагностики:
- разрешение DNS (`A`, `AAAA`, обратный `PTR`);
- проверка базовых TCP-портов с замером задержки (`ms`);
- проверка доступности по `HTTPS`/`HTTP` и ключевых HTTP-заголовков;
- получение базовой информации об IP/ASN через бесплатный публичный endpoint `ipwho.is`;
- автоматическое сохранение отчётов в формате JSON в папку `reports/`.

## Быстрый старт

Требуется **Python 3.10+** (сторонние библиотеки не нужны).

```bash
./setup_and_run.sh example.com

Либо напрямую через Python:
python3 netpulse.py example.com -p 80,443
Параметры запуска
Маркер списка target — домен или IP-адрес (проверяйте только ресурсы, на проверку которых у вас есть право).
Маркер списка -p, --ports — порты через запятую (например: -p 22,80,443).
Маркер списка -t, --timeout — таймаут в секундах (по умолчанию 2.5).
Маркер списка --no-geo — отключить внешний запрос IP-геолокации/ASN.
Маркер списка --no-save — не сохранять JSON-отчёт в папку reports/.
Ограничения
Маркер списка Внешний IP/ASN-запрос зависит от доступности стороннего бесплатного сервиса ipwho.is и наличия доступа в интернет.
